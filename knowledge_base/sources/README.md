# مجلد ملفات المتشابهات (PDF Sources)

ضع ملفات الـ **PDF** الخاصة بمتشابهات القرآن الكريم هنا في هذا المجلد (`knowledge_base/sources/`).

### أمثلة للكتب والمراجع المدعومة:
- كتب ضبط المتشابهات بالتقعيد
- ملاك التأويل لابن الزبير الغرناطي
- البرهان في توجيه متشابه القرآن للكرماني
- دليل الحيران في متشابهات القرآن
- أي ملخص أو كتاب PDF معتمد لديك للمتشابهات اللفظية

### كيفية المعالجة والفهرسة:
بعد وضع ملفات الـ PDF في هذا المجلد، شغّل الأمر التالي لفهرستها وإضافتها لقاعدة المعرفة:
```bash
npm run ingest:kb
```
يقوم هذا الأمر باستخراج مواضع المتشابهات والآيات والضوابط بدقة 100% بدون أي هلوسة، ويجعل كافة الأسئلة والخيارات والبدائل محصورة تماماً في هذه المراجع.

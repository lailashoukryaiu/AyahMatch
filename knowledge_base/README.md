# نظام قاعدة المعرفة المعتمدة (Quran Mutashabihat Knowledge Base)

تم تصميم هذا النظام لضمان **حصر كافة الأسئلة والخيارات والبدائل والمشتتات (Distractors) بنسبة 100% في المراجع والكتب المعتمدة فقط**، مع منع أي توليد عشوائي أو هلوسة من الذكاء الاصطناعي في آيات القرآن الكريم.

---

## 📁 الهيكل التنظيمي (Folder Structure)

```
knowledge_base/
├── README.md                          # هذا الدليل التوضيحي
├── sources/                           # ضع ملفات الـ PDF الخاصة بك هنا
│   └── README.md
├── extracted/                         # ملفات JSON المستخرجة لكل كتاب
└── sample_template.json               # قالب البيانات الدقيقة للمتشابهات
```

---

## 🛡️ مبادئ الحصر والتوثيق (Strict Grounding Rules)

1. **الخيارات والبدائل (Options & Distractors)**:
   - الخيار الصحيح هو اللفظ الدقيق للآية المحددة بالسورة ورقم الآية.
   - البدائل والمشتتات **تقتصر حصرياً** على الآيات أو المواضع المشابهة المذكورة في المرجع، ولا يتم تأليف أي بدائل من خارج القرآن أو من غير المواضع المتشابهة.

2. **قواعد وضوابط الحفظ (Mnemonics & Rules)**:
   - كل سؤال مرتبط مباشرة بضابط الحفظ المستخرج من كتاب المتشابهات (مثل: قاعدة الضبط بالترتيب الهجائي، أو مراعاة اسم السورة، أو السياق).

3. **المرجع والتوثيق (Provenance Tracking)**:
   - كل موضع موثق باسم الكتاب وصفحته لضمان الموثوقية الكاملة.

---

## 🚀 كيفية إضافة وفهرسة ملفات PDF جديدة

1. انسخ ملفات الـ PDF إلى المجلد:
   `knowledge_base/sources/`

2. شغّل أمر المعالجة:
   ```bash
   npm run ingest:kb
   ```

3. يقوم البرنامج باستخراج المتشابهات وربطها تلقائياً بالتطبيق والتدريب والبحث وكتاب الضبط.
